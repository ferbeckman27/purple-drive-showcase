# Velocity — Purple Drive Showcase 🏎️✨

**Purple Drive Showcase** é uma *landing page* moderna e dinâmica projetada para destacar veículos esportivos de alta performance. Desenvolvida para concessionárias automotivas de alto padrão, a aplicação combina um design *dark* elegante em tons de roxo com navegação fluida e animações interativas.

🚀 **Live Demo:** [purple-drive-showcase.lovable.app](https://purple-drive-showcase.lovable.app)

---

## 📌 Sobre o Projeto

O objetivo principal deste projeto é oferecer uma vitrine digital interativa e envolvente para clientes do setor automotivo esportivo, permitindo a visualização detalhada de modelos de veículos e facilidade de contato.

### Key Features
* 🏎️ **Vitrine de Veículos:** Exibição de modelos esportivos com especificações técnicas e ação *Saiba mais*.
* 🎨 **Design Moderno:** Interface responsiva com tema escuro/roxo e animações dinâmicas.
* 🧭 **Navegação Intuitiva:** Seções bem estruturadas (*Home*, *Carros* e *Fale Conosco*).
* ⚡ **Alta Performance:** Construído com ferramentas focadas em velocidade e DX moderna.

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
Certifique-se de ter o **Node.js** (versão 18+) e o **npm** instalados em sua máquina.

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/ferbeckman27/purple-drive-showcase.git](https://github.com/ferbeckman27/purple-drive-showcase.git)
Acesse o diretório do projeto:

Bash
cd purple-drive-showcase
Instale as dependências:

Bash
npm install
Inicie o servidor de desenvolvimento:

Bash
npm run dev
Abra o navegador e acesse http://localhost:5173 (ou a porta indicada no terminal).
